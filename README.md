## The entry

`main.py` writes one text to `/output/entry.txt` — exactly two lines:

- **Line one** warns the past self about one specific moment, in a single sentence.
- **Line two** says in one sentence why that moment mattered and what changed because of it.

The text is 1–280 characters of UTF-8, as the gate requires. A judge model
compares entries two at a time, weighing how concrete the moment is and how
clearly the second line traces cause and effect.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```

No network, no dependencies, no secrets — just Python 3.
